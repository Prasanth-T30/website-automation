# Runtime dependencies, fully pinned — the exact set the test suite passes
# against, and the set the container installs.
#
# Pinned all the way down, transitive packages included, because an unpinned
# build is not reproducible in the way that matters. A Cloud Run image built
# from `pyproject.toml` ranges once resolved a newer google-cloud-firestore
# that percent-encoded the database id and answered every query with
#
#     400 Invalid database id %28default%29
#
# on code that had not changed. `pyproject.toml` stays the source of truth for
# what this service needs and why; this file decides which versions ship.
#
# To regenerate after changing pyproject.toml:
#
#     uv pip compile pyproject.toml -o requirements.txt
#
# uvicorn carries its [standard] extras here as separate pins, since a
# requirements file resolves each distribution by name.
